# Project 04 - Web Scraper for Headlines & Quotes

Build a web scraper using BeautifulSoup and requests to extract quotes into a file.

## Requirements Met
- HTTP requests handling
- HTML tag inspection & extraction
- Data formatting into clean text / JSON

## How to Run
pip install -r requirements.txt
python web_scraper.py

## Output
- quotes.json
- quotes.csv
- quotes.txt
